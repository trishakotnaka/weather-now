# Weather API

A simple RESTful Weather API built using Kotlin and Ktor.

## Features

- Get weather information by city
- Temperature
- Feels-like temperature
- Weather condition
- Humidity
- Wind speed
- REST API endpoint

## Technologies Used

- Kotlin
- Ktor
- Gradle
- REST API
- wttr.in Weather Service

## API Endpoint

### Get Weather

```text
GET /weather/{city}
